# Personal Brand Website

Apple-inspired personal brand site for a software engineering manager with 15+ years of web development experience. Built with Next.js 14, TypeScript, and Tailwind CSS.

## Sections

- Hero
- About
- Skills
- Projects
- Experience
- Writing
- Contact

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

Edit `src/app/page.tsx` for name, links, and content. Update `src/app/layout.tsx` for metadata.
